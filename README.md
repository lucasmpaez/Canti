# ترانيم · Canti

App web (installabile sul telefono) con canti e preghiere — Angelus, preghiere in arabo con traslitterazione e traduzione italiana, canti in arabo, in italiano e in altre lingue.

Apri https://lucasmpaez.github.io/Canti/ in Chrome (o Safari su iPhone) e tocca **Scarica l'app**: funziona anche senza connessione.

Per aggiornare l'app cambia `VERSIONE` in `sw.js`.
